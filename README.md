# 📚 AI PDF Assistant

An AI-powered PDF question-answering application built using Python, Streamlit, ChromaDB, and Gemini.

## 🚀 Features

- Upload PDF documents
- Extract text from normal PDFs
- OCR support for scanned PDFs
- Intelligent text chunking
- Semantic search using embeddings
- ChromaDB vector database
- Retrieval-Augmented Generation (RAG)
- Conversational follow-up questions
- Query rewriting
- Result reranking
- Page and section based sources
- Multiple PDF management
- PDF deletion
- Chat history
- Gemini API integration
- API error handling
- Secure API key management

## 🧠 Architecture

PDF
↓
Text Extraction / OCR
↓
Chunking
↓
Embeddings
↓
ChromaDB
↓
Semantic Retrieval
↓
Reranking
↓
Relevant Context
↓
Gemini
↓
Answer + Sources
